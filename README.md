# Image-Captioning-BILSTM

Image-Captioning-BILSTM

The Image Captioning system combines the power of two advanced techniques: object detection and natural language processing. YOLOv5 is used for real-time object detection in images, identifying key objects and their locations. A Bidirectional Long Short-Term Memory (BiLSTM) network is then employed to generate accurate captions based on the detected objects, by processing the image features and creating descriptive sentences. This project aims to improve automated image captioning systems by leveraging the strengths of both deep learning models for more context-aware and meaningful descriptions.
